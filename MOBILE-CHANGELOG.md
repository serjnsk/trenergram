# Мобильная адаптация кабинета тренера — чейнджлог

Сверяйтесь с этим файлом, когда правите вёрстку или скрипты кабинета (`mvp/`): мобильная версия держится на нескольких неочевидных зависимостях, и десктопная правка легко ломает телефон.

- Дата: 12 октября 2026
- Охват: все страницы кабинета тренера — `index`, `calendar`, `clients`, `client`, `groups`, `exercises`, `exercise`, `blocks`, `workouts`, `programs`, `program`, `profile`, `constructor` (клиент / группа / шаблон блока и тренировки / мастер).
- Вне охвата: клиентское приложение `mvp/client/`, лендинг `mvp/landing/`, `design-preview` в ветке `main`; планшеты (761–1120 px) — остались в прежнем виде.
- Целевые размеры проверки: 390×844 (iPhone), 360×800 (Android). Десктоп 1920×1080 не должен отличаться от прежнего.

## 1. Принципы

1. **Десктоп не трогаем.** Вся адаптация — в двух новых файлах; каждое правило CSS лежит внутри одного `@media (max-width:760px)`.
2. **Разметку страниц не переписываем.** Страницы по-прежнему рисуют те же классы; телефонный вид получается переопределением CSS и небольшим JS-слоем.
3. **Зоны касания ≥ 44 pt**, шрифт полей ≥ 16 px (иначе iOS Safari приближает страницу при фокусе), нижняя навигация под большой палец, окна — шторками снизу (HIG).
4. **Плоский язык темы сохранён:** тон и линия, без теней (исключение — затемнение за шторками).

## 2. Затронутые файлы

| Файл | Что сделано |
|---|---|
| `mvp/assets/mobile.css` | **Новый.** Все мобильные правила. Подключён последним в `<head>`, поэтому перебивает остальные при равной специфичности |
| `mvp/assets/mobile.js` | **Новый.** Нижняя панель, шторка «Ещё», шторка правой панели конструктора, кнопка «назад», сортировка списков, перетаскивание пальцем, умная липкая шапка календаря, блокировка автофокуса |
| Все 13 страниц кабинета | В `<head>` после последнего `assets/*.css` добавлены `<link rel="stylesheet" href="assets/mobile.css">` и `<script src="assets/mobile.js"></script>`. Новая страница кабинета обязана добавить то же |
| `mvp/calendar.html` | Константа `HEAD()` (отступ при прокрутке к месяцу/дню) на телефоне считается как `52 + высота .monh`, а не как `58 + высота шапки календаря` — шапка календаря там уже не липкая постоянно |
| `mvp/design.html` | `mobile.css/js` **не подключены** (страница вне меню кабинета). Добавлен свой `@media (max-width:760px)`: поля `.d-wrap`, перенос строк `.d-tp` |
| `mvp/README.md` | Раздел «Мобильная версия» |

Больше ни один скрипт и ни один стиль десктопа не менялись.

## 3. mobile.js — что делает и от чего зависит

Скрипт подключён в `<head>`, а UI строит по `DOMContentLoaded`. Всё, что зависит от ширины, проверяется через `matchMedia('(max-width:760px)')`.

| Механизм | Поведение | Зависимости — что не ломать |
|---|---|---|
| **Нижняя панель `.mtabs`** | Три главных раздела (`index`, `calendar`, `clients`) и «Ещё» | Пункты берутся из массива `NAV` в `assets/nav.js` и иконок `ICON`. Новый раздел в `NAV` попадает в шторку «Ещё» автоматически; чтобы вынести его в панель, добавьте в `MAIN` в `mobile.js` (и учтите `grid-template-columns:repeat(4,1fr)` у `.mtabs`) |
| **Шторка «Ещё» `.msh`** | Остальные пункты `NAV` + профиль | Активный пункт берётся из `#nav a.on` (его ставит `renderNav`), запасной — из имени файла и карты `PARENT` (`client.html→clients.html` и т.д.) |
| **Кнопка «назад» `.mback`** | В шапке страниц `client`, `exercise`, `program`, `constructor`. Если пришли с той же origin — `history.back()`, иначе ссылка на раздел | Карта `BACK` в `mobile.js`. Шапку перерисовывает `renderTop()` — кнопку восстанавливает `sweep()` |
| **Шторка правой панели конструктора** | Кнопка `.mrail-btn` над днём, затемнение `.mrail-bd`, шапка `.mrail-x` внутри `.rail` | Селекторы `.rail` и `.cons main` в `constructor.html`. `#railhead/#src/#railfoot` перерисовываются страницей — сам `.rail` остаётся |
| **Сортировка списков `.msort`** | Вместо скрытой шапки таблицы — «Сортировка» + направление. Нажимает ту же `<th data-sort>` | Таблицы строятся `dataTable()` в `ui.js` (и `clients.html` с теми же `data-sort`). Логику сортировки не дублируем |
| **Пустые ячейки `.mnil`** | Ячейка с прочерком в карточке скрывается | Только таблицы `.tbl[data-tbl]` кроме `data-tbl="pm"` |
| **Перетаскивание пальцем** | Касание ручки `.gr` → `mousedown`, `dragstart`, `dragover`, `drop`, `dragend` с `DataTransfer`; автопрокрутка у краёв | Работает на родных обработчиках `trainer.js` (раздел «ПЕРЕТАСКИВАНИЕ») и `.cyc` в `program.html`. Ручка должна быть `.gr` внутри `.line` / `.blk` / `.doc` / `.cyc`. Если смените механику DnD в `trainer.js` — проверьте мост |
| **Умная шапка календаря** | Класс `.mhid` на `.calwrap .wkh` при прокрутке вниз | Структура календаря в `calendar.html` |
| **Блокировка автофокуса** | Подменён `HTMLElement.prototype.focus`: на телефоне игнорирует `focus()` для `input#q`, `.pane-h input`, `.dsel-s input`, `#cl-q`, если пользователь не печатал последние 600 мс | Страницы списков вызывают `focus()` после каждой перерисовки (иначе клавиатура выскакивала бы от тапа по фильтру). Новое поле поиска с таким же поведением добавьте в селектор |
| **`sweep()`** | `MutationObserver` на документе: `markNil`, `sortBar`, `backBtn`. На десктопе сразу выходит | Тяжёлый обход не добавляйте — вызывается на каждую мутацию DOM |

## 4. mobile.css — что изменено по областям

### Каркас и навигация
- `.app` вместо сетки — блок, `.nav` скрыт; `.main` получает отступ снизу `--tabh + safe-area`.
- Переменные: `--tabh:58px`, `--mtop:52px`, `--sab:env(safe-area-inset-bottom)`.
- Шапка 52 px; заголовок с многоточием; «Создать тренировку» — плюс 44×44 в акцентном круге (`font-size:0` + маска `::before`, подпись остаётся для скринридера).
- `viewport-fit=cover` дописывается в `<meta viewport>` скриптом (иначе `safe-area-inset-*` нулевые).

### Окна, всплывашки, списки выбора
- `.ov` прижат к низу, `.md` — шторка с закруглением сверху, макс. 92dvh; кнопка закрытия 44×44; подвал переносится, кнопки по 46 px.
- Шторками снизу стали `.sug.dsl` (выпадающие списки `dd.js`), `.sug.clipick` (выбор клиента), `.sug.dpick` и `.sug.dpk` (выбор даты), `.sug.setup` (формат блока). Позицию, которую `dd.js` и `nav.js` считают под мышь, перебиваем `!important`. Затемнение — `box-shadow:0 0 0 100vmax`.
- Подсказки у поля ввода (`.sug.exsug` и простой `.sug`) остаются у поля, но ограничены шириной экрана.
- Тост поднят над нижней панелью, `z-index:140`.

### Списки и таблицы
- `.tbl[data-tbl]` (кроме `pm`) → карточки: `thead` скрыт, строка — flex/grid. Подписи полей через `td:nth-child(n)::before`, **привязаны к порядку колонок**: клиенты (`cli`), группы (`grp`), базы (`lib-блок`, `lib-тренировка`, `lib-программа`), упражнения (`ex`). **Добавили или переставили колонку — обновите `::before` и номера `nth-child` в `mobile.css`.**
- Таблицы без `data-tbl` (замеры, платежи в карточке клиента, история платежей в профиле) остаются таблицами; замеры прокручиваются по горизонтали. В `pm` скрыта колонка «Обновлён».
- `.pane-h` на телефоне не липкий: сетка 2 колонки, поиск и кнопки на всю строку. Фильтры-чипы — одна горизонтально прокручиваемая строка.

### Дашборд
- KPI — 2 колонки; перерасход лимита — колонкой; вкладки `.tabs2` прокручиваются; событие ленты `.fev` — сетка «значок | текст», действие отдельной строкой под текстом.

### Календарь
- Месяц списком дней: `.days` в одну колонку, `.dow` и `.day.void` скрыты. Липкий заголовок месяца `.monh` под шапкой. Отметка дня (`.bk-box`) 24 px с зоной касания 44; строка массовых действий `.bk-bar` на всю ширину над нижней панелью (`left:8px !important`, потому что `bulk.js` ставит `left` инлайном).

### Карточка клиента
- Шапка колонками, контакты в 2 колонки, заметка колонкой, табы-якоря прокручиваются и липнут под шапкой (`top:var(--mtop)`; якорный скролл в `client.html` использует `HEAD = 58 + 52` — значение совпадает), две недели — карточки по две в ряд, оплата/замеры/максимумы — одной колонкой.

### Страницы элементов, профиль, группы
- `.ehead`, `.egrid` (боковая колонка уходит вниз, `sticky` снят), цикл программы `.cyc[draggable]` — сетка «ручка / номер / выбор / ✕ + мета / открыть».
- Профиль: `.prof` одной колонкой, `.side` без `sticky`, тарифы `.plans` колонкой, переключатель 50×30.

### Конструктор
- `.cons.cwide` — блок; `.rail` — фиксированная шторка (86dvh), `translateY(105%)` → `body.mrail-on .rail{transform:none}`; `.railtog` скрыт.
- Полоса недель `#strip` — горизонтальная прокрутка карточек по 150 px.
- Шапка дня `.doch` переносится, название на своей строке (`order:5`); шапка блока `.blkh` — две строки.
- Строка упражнения `.line`: название и ✕ первой строкой, схема и нагрузка `.prm` второй (`order:4`, отступ под ручку); ширину названия `--nmw` (выравнивание `alignNames`) на телефоне отключаем `width:auto !important`.
- Связка, суперсет (`.doc.quick .ssh …`), `.kind`-переключатель, `.pf`-поля — увеличены до 40 px.
- Панель сохранения `.pubbar` липнет над нижней панелью (`bottom:calc(var(--tabh) + var(--sab))`), подсказка `s` скрыта.
- Ручки `.gr` — `touch-action:none`, чтобы касание не прокручивало страницу.

## 5. Правила для разработчика

1. **Новая страница кабинета:** подключить `mobile.css` (после остальных стилей) и `mobile.js` (в `<head>`), вставить в `NAV` (`nav.js`), проверить на 390×844.
2. **Новая колонка в таблице-списке:** обновить подписи `::before` и `nth-child` в блоке «клиенты / базы / упражнения / группы» `mobile.css`. Не забыть про `mnil` (прочерк в ячейке скрывается).
3. **Правите `.doc.quick …` или другие правила с высокой специфичностью** — мобильные перекрытия должны быть не слабее (так сделано для `.doc.quick .ssh .ssf input`).
4. **Селекторы, на которые опирается JS:** `#topbar`, `#nav a.on`, `.rail`, `.cons main`, `.calwrap .wkh`, `.monh`, `.gr` + `.line/.blk/.doc/.cyc`, `th[data-sort]`, `.tbl[data-tbl]`, `.pane-h`. Переименование без правки `mobile.js` отключит соответствующий механизм молча.
5. **Новый `focus()` на поле поиска** — добавьте селектор в блокировку автофокуса, иначе на телефоне поднимется клавиатура.
6. **Новая всплывашка, привязанная к кнопке (`.sug …`):** если ширина фиксирована, добавьте её класс в список шторок.
7. **Инлайн-стили со страниц** (`style="width:260px"` и т.п.) перебиваются только `!important` — так сделано для полей `.pane-h`.
8. **Не использовать hover как единственный путь** к действию: на тач-экране его нет (кнопки `+` в панели календаря/баз для этого сделаны видимыми всегда).
9. **Заголовки и якорные отступы** с жёстким `58px` (шапка десктопа) на телефоне должны быть `52px` (`--mtop`).

## 6. Как проверять

- Скриншоты: headless Chrome не бывает уже 500 px, поэтому снимать страницу в `<iframe width=390>` на странице-обвязке (iframe не должен быть из `file://` на другую origin, если нужен доступ к DOM).
- Интерактив: панель браузера в Claude Code, `resize_window mobile` (375×812).
- Перед коммитом: прогон всех страниц на ошибки консоли (команда в памяти проекта `page-sweep-before-deploy`) и проверка на 1920×1080, что десктоп не изменился.
- Проверка переполнения: `document.documentElement.scrollWidth` не должен превышать ширину окна (учитывайте полосу прокрутки в iframe).

## 7. Известные ограничения

- Проверено в эмуляции Chrome; на реальных iPhone/Android не проходили. Особенно — перетаскивание в конструкторе и поведение клавиатуры в полях.
- Планшеты 761–1120 px: десктопное меню слева 238 px, как раньше.
- Перетаскивание дня (ручка в шапке дня) на день в полосе недель работает тем же мостом, но на телефоне полоса недель по умолчанию скрыта.
- Для тачпадов/гибридов: мост `touchDnD` срабатывает только на touch-события и только при ширине ≤ 760 px.
