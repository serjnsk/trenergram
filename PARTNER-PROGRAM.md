# Партнёрская программа тренеров — изменения для разработки

- Дата: 28 октября 2026
- Прототип (ветка `prototypes`):
  - кабинет, таб «Партнёрская программа»: https://serjnsk.github.io/trenergram/prototype/profile.html#partner (вывод средств включён — `profile.html?payout=1#partner`)
  - админка, страница программы: https://serjnsk.github.io/trenergram/prototype/admin/partners.html?role=admin
  - админка, вкладка в карточке тренера: https://serjnsk.github.io/trenergram/prototype/admin/trainer.html?id=t2&tab=prt&role=admin
- Тренеры и суммы в демо вымышленные, состояние хранится в `localStorage`.

## 1. Суть

1. Тренер приглашает других тренеров по своей партнёрской ссылке. С каждой оплаты подписки приглашённого тренера ему начисляется процент.
2. Процент общий для всех, его задаёт администратор. Конкретному тренеру администратор может поставить свой процент.
3. Начисления копятся на партнёрском счёте тренера. Тренер переводит их на **баланс аккаунта**, а баланс списывается в счёт следующего платежа за подписку.
4. **Вывод средств** деньгами по умолчанию выключен у всех. Администратор включает его конкретному тренеру. Вывод ручной: тренер оставляет заявку, администратор связывается с ним, платит вне сервиса и отмечает заявку в админке.

## 2. Правила расчёта

1. Начисление = сумма оплаты подписки приглашённого × процент партнёра **на момент оплаты**. Округление до рубля.
2. Смена процента (общего или своего) уже начисленное не пересчитывает и действует со следующих оплат. Поэтому начисление хранит базу и процент.
3. **Доступно** = начисления − переводы на баланс − заявки на вывод (ждут выплаты и выплаченные). Отклонённая заявка возвращает сумму в «Доступно».
4. Сумма заявки резервируется в момент создания.
5. Сумма перевода и заявки — целое число от 1 до «Доступно». Перевод на баланс необратим: вывести деньги с баланса нельзя.
6. Списание за подписку идёт сначала с баланса, остаток — с карты. Если баланс не меньше цены, всё списывается с баланса.
7. Партнёрская ссылка имеет вид `trenergram.ru/p/КОД`. Код случайный, 6 символов, без похожих букв и цифр, как у ссылки для клиентов. Приглашённый привязывается к партнёру при регистрации по ссылке.
8. Если условия тренера совпали с общими (общий процент, вывод выключен), запись своих условий удаляется. После этого тренер следует за общим процентом при его смене.

## 3. Данные (предложение)

| Где | Поле | Описание |
|---|---|---|
| настройки сервиса | `partner_default_percent` | целое 0–100, в демо 20 |
| тренер | `partner_code` | код партнёрской ссылки |
| тренер | `referred_by` | id партнёра, ставится при регистрации по ссылке |
| тренер | `partner_percent` | свой процент; `null` — действует общий |
| тренер | `payout_enabled` | вывод средств, по умолчанию `false` |
| тренер | `account_balance` | баланс аккаунта, ₽ |
| движение по счёту | `type` | `accrual` — начисление, `to_balance` — перевод на баланс, `payout` — заявка на вывод |
| движение по счёту | `amount`, `created_at` | сумма и дата |
| движение по счёту (`accrual`) | `referred_trainer_id`, `payment_id`, `base_amount`, `percent` | чья оплата, с какой суммы и по какому проценту |
| движение по счёту (`payout`) | `status`, `resolved_at`, `resolved_by` | `pending` / `paid` / `rejected`, когда и кто обработал |

## 4. Кабинет тренера — `mvp/profile.html`

### 4.1 Таб «Партнёрская программа» (`#partner`)

Третий таб после «Профиля» и «Подписки».

**Карточка программы:**
- текст с текущим процентом тренера;
- поле со ссылкой и кнопкой «Скопировать ссылку»;
- сводка из 4 ячеек: «Ваш процент», «Приглашено N · платят M», «Заработано всего», «Доступно»;
- подвал: строка про баланс аккаунта и кнопки «Вывести» (только при `payout_enabled`) и «Перевести на баланс». Обе кнопки неактивны, когда «Доступно» = 0.

**Окно «Перевести на баланс».** Сумма по умолчанию — всё доступное. Кнопка «Перевести N ₽», подсказка «Доступно N ₽».

**Окно «Вывести средства».** Текст: «администратор свяжется с вами и договорится о выплате, пока заявка ждёт, сумма в резерве». Поле суммы, подсказка с телефоном тренера, кнопка «Отправить заявку на N ₽».

**«Движение по счёту»** — таблица с колонками «Дата», «Операция», «Сумма»:
- «Оплата подписки · Имя Фамилия», под ней «1 990 ₽ × 20%», сумма «+398 ₽» зелёным;
- «Перевод на баланс аккаунта», «−800 ₽»;
- «Вывод средств» со статусом «ждёт выплаты», «выплачено» или «отклонено». Отклонённая строка серая, сумма зачёркнута.
- Новые операции сверху, в пределах одного дня последняя тоже сверху. У дат текущего года год не пишется.
- Пустое состояние: «Начислений пока не было — они появятся после первой оплаты приглашённого тренера».

### 4.2 Таб «Подписка»

- Под картой новая строка: «N ₽ на балансе аккаунта — спишем в счёт следующего платежа» со ссылкой «Пополнить» на `#partner`. При пустом балансе: «Баланс аккаунта пуст — пополняется из партнёрской программы».
- В подвале расписано списание: «Следующий платёж 3 990 ₽ — 14 декабря 2026, через 47 дней: 800 ₽ с баланса, 3 190 ₽ с карты».

### 4.3 Мобильная версия (≤ 760 px)

- Табы стоят в одну строку и прокручиваются вбок. Если открытый таб не виден целиком, строка прокручивается к нему.
- В подвале карточки программы текст идёт первой строкой, кнопки — под ним во всю ширину.

## 5. Админка

### 5.1 Страница «Партнёрская программа» — `mvp/admin/partners.html`

- В меню: «Настройки → Партнёры». Страница только для администратора: маркетолог пункта меню не видит, а по прямому адресу получает заглушку «Раздел доступен администратору».
- **«Процент по умолчанию»** — поле 0–100 и кнопка «Сохранить». Кнопка активна, когда значение изменено; Enter тоже сохраняет. Подпись сообщает, у скольких тренеров свой процент, и что новый процент действует со следующих начислений.
- **«Вывод средств»** — только информация: «по умолчанию выключен» и «включён у N тренеров».
- **«Заявки на вывод»** — колонки «Тренер» (имя и телефон), «Заявка» (дата и время), «Сумма», «Статус».
  - Ждущие заявки стоят сверху, у них кнопки «Выплачено» и «Отклонить».
  - Обработанные заявки серые, с чипом «выплачено 19 сен» или «отклонено …».
  - Над таблицей подсказка про выплату вне сервиса. Если заявок нет совсем, блок не показывается.
- **«Партнёры»** — тренеры, которые привели хотя бы одного тренера или у которых есть свои условия. Сортировка по заработанному.

  | Колонка | Содержимое |
  |---|---|
  | Тренер | имя (ссылка на карточку) и город |
  | Приглашено | «N · платят M» |
  | Процент | «N%» с пометкой «свой» или «общий» |
  | Заработано | сумма |
  | Доступно | сумма и, если есть заявка, «ещё N ₽ в заявке» |
  | Вывод средств | переключатель, сохраняется сразу |
  | — | карандаш, открывает окно условий |

- **Кнопка «Задать условия тренеру»** открывает окно:
  - выбор тренера (в списке только те, у кого ещё нет своих условий);
  - процент — «Общий · 20%» или «Свой» с полем ввода;
  - переключатель «Вывод средств».

  Без выбранного тренера сохранить нельзя. Если условия совпадают с общими, окно подсказывает это и не сохраняет.
- **Карандаш** открывает то же окно для партнёра, в нём есть ещё кнопка «Вернуть общие условия».

### 5.2 Карточка тренера — вкладка «Партнёрская программа»

- Видна только администратору. Стоит третьей после «Ленты» и «Онбординга». Число ждущих заявок показано на вкладке красным.
- Блок «Условия» тот же, что в окне на странице программы, но изменения сохраняются сразу.
- Сводка из 5 ячеек: «Приглашено», «Заработано», «На баланс аккаунта», «Выплачено», «Доступно».
- Заявки этого тренера с теми же кнопками «Выплачено» и «Отклонить».
- «Приглашённые тренеры»: имя, статус («платит», «пробный период», «не продлил») и дата регистрации.
- Ссылка «Общий процент и все партнёры» ведёт на страницу программы.
