# 07 · Одна программа на группу

- **Рубрика:** Фича за 15 секунд
- **Формат:** 9:16, 15 с
- **Площадки:** Reels, Shorts, TikTok
- **Одна мысль:** тренер пишет тренировку один раз для группы, и она встаёт в календарь всем десяти участникам
- **Экран:** `groups.html` → `calendar.html?group=grp1` → `constructor.html?group=grp1&date=…`
- **Сцена:** [scenes/07-groups.html](../scenes/07-groups.html)

## Раскадровка

| Время | Кадр / действие | Подпись |
|---|---|---|
| 0–1 с | Весь экран «Группы»: одна группа «ЛФК» | **ОДНА ПРОГРАММА — ДЕСЯТЬ ЧЕЛОВЕК** / Тренировку пишете один раз |
| 1–2,2 с | Наезд на строку группы: аватары, «10 участников», кнопка «Календарь» | |
| 2–3,1 с | Курсор на «Календарь», клик: открывается календарь группы | |
| 3,2–4,4 с | Наезд на селектор «ЛФК · 10 участников» и неделю с тренировками группы | |
| 4,6–5,9 с | Курсор на ближайший день с тренировкой (ищется по признаку), клик: конструктор этого дня | |
| 6–7 с | Крупно: «10 участников · Стоит у всех. Правка здесь меняет тренировку у всех участников» и первые имена | **ПРАВКА — У ВСЕХ СРАЗУ** / Встаёт в календарь каждому |
| 7,7–9,3 с | Панорама по именам остальных участников | |
| 9,9–12,1 с | Отъезд: вся полоса с десятью участниками и тренировка, подсветка полосы | |
| 12,4–15 с | Логотип и слоган | Автоматизируем тренерскую рутину |

## Текст поста

Десять человек на ЛФК занимаются по одной программе? Не нужно расписывать каждому. Соберите их в группу и составьте тренировку один раз: она встанет в календарь всем участникам. Поправили упражнение — поменялось у всех.

## Заметки

- В сцене два перехода по ссылкам внутри iframe. Чтобы в рендер не попал белый экран загрузки, сцена подменяет `__scene.seek`: кадр после клика возвращает промис и ждёт `load` новой страницы, шрифты и 0,9 с на её стартовую прокрутку. Движок не меняли.
- Демо-данные считаются от сегодняшней даты: день в календаре берётся как первый день с тренировкой в левой части месяца, видимый на экране.
