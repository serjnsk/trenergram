# 12 · Авторасчёт весов

- **Рубрика:** Фича за 15 секунд
- **Формат:** 9:16, 15 с
- **Площадки:** Reels, Shorts, TikTok
- **Одна мысль:** тренер задаёт нагрузку в процентах от максимума, каждый атлет получает свой вес в килограммах, а после нового рекорда веса пересчитываются сами
- **Экран:** конструктор, тренировка группы «Утро 7:00», блок «Становая тяга», таблица Атлет / 1ПМ / Вес
- **Серия:** фичи с лендинга, вариант «схема» (упрощённый интерфейс с логотипом, слова только у главного)
- **Сцена:** [scenes/12-weights.html](../scenes/12-weights.html), экран [schema/12-weights.html](../scenes/schema/12-weights.html)
- **Лендинг:** «Авторасчёт весов»

Арифметика (80 % от 1ПМ, округление до 2,5 кг): Иван П. 210 → 167,5 кг; Мария С. 125 → 100 кг; Олег Р. 170 → 135 кг, после рекорда 180 → 145 кг; Аня К. 95 → 75 кг.

## Раскадровка

Режим «телефон» со схематичным экраном: шапка с логотипом и разделом «Конструктор», второстепенное — серыми плашками. Фича выделяется затемнением вокруг, оранжевой рамкой и стикером сбоку, нажатия показаны касанием пальца.

| Время | Кадр / действие | Подпись / стикер |
|---|---|---|
| 0–1 с | Блок «Становая тяга», пустое поле схемы, столбец «Вес» — серые плашки | **ПРОЦЕНТЫ — В КИЛОГРАММЫ** / Нагрузка от 1ПМ, 3ПМ или рекорда |
| 1–3,6 с | Выделено поле «Схема», набирается «3 × 3 · 80 %» | стикер «Схема и процент» |
| 3,7–4,5 с | Выделена кнопка «Рассчитать», касание | |
| 4,7–7 с | Выделена таблица: веса появляются по очереди — 167,5 / 100 / 135 / 75 кг | стикер «Свой вес — до 2,5 кг» |
| 7,2–9,2 с | Сверху приходит плашка «Олег Руденко · Рекорд: становая 180 кг» | **НОВЫЙ РЕКОРД — ВЕСА ПЕРЕСЧИТАНЫ** / Клиент видит только килограммы; стикер «Олег поставил рекорд» |
| 9,3–12,2 с | Строка Олега: 1ПМ 170 → 180, метка «рекорд», вес 135 → 145 кг (оранжевая плашка) | стикер «135 → 145 кг само» |
| 12,4–15 с | Логотип и слоган | Автоматизируем тренерскую рутину |

## Текст поста

Пишете в программе «80 %» — и считаете килограммы для каждого вручную? В Тренерграме нагрузка задаётся от максимума: 1ПМ, 3ПМ или рекорда. Каждому атлету приходит готовый вес, округлённый до 2,5 кг — как блины на штанге. Поставил новый рекорд — веса в следующих тренировках пересчитаются сами. Клиент видит только килограммы, без процентов и расчётов.
