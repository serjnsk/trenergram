# 05 · Месяц клиента одним экраном

- **Рубрика:** Фича за 15 секунд
- **Формат:** 9:16, 15,5 с
- **Площадки:** Reels, Shorts, TikTok
- **Одна мысль:** весь месяц клиента виден сразу, со статусом каждого дня, и с несколькими днями можно работать одним действием
- **Экран:** `calendar.html?client=c1&view=compact`, вид «Свёрнуто» (дата, статус и название, весь месяц на одном экране)
- **Сцена:** [scenes/05-calendar.html](../scenes/05-calendar.html)

## Раскадровка

| Время | Кадр / действие | Подпись |
|---|---|---|
| 0–1 с | Весь кабинет: календарь Артёма Ковалёва, текущий месяц в свёрнутом виде | **МЕСЯЦ КЛИЕНТА ОДНИМ ЭКРАНОМ** / Статусы всех дней — сразу |
| 1–2,2 с | Камера на сетку текущего месяца | |
| 2,6–3,8 с | Наезд на сегодняшний день и две клетки рядом: опубликованная тренировка (глаз), отдых, соревнование (кубок) | |
| 3,9–5,2 с | Подсветка этих трёх клеток | |
| 5–6,2 с | Камера на неделю после сегодняшней | |
| 5,4–6,4 с | Курсор на галочку первого дня, клик: день выбран | **НЕСКОЛЬКО ДНЕЙ — ОДНИМ ДЕЙСТВИЕМ** / Перенос, копия, публикация |
| 6,6–7,6 с | Курсор на третий день, Shift+клик: выбраны все дни с тренировкой между ними, снизу появляется строка действий | |
| 8–10,2 с | Камера на строку: «Выбрано 3», Копировать, Переместить, Опубликовать, В черновик, Удалить; подсветка | |
| 9,2–10,3 с | Курсор на «Переместить», клик | |
| 10,6–12,6 с | Наезд на окно переноса: кому, с какой даты, как раскладывать; курсор у кнопки «Переместить» | |
| 13–15,5 с | Логотип и слоган | Автоматизируем тренерскую рутину |

Дни не зашиты: сцена берёт сегодняшнюю клетку (`.day.today`) и ряд недели под ней, а в нём три дня с тренировкой подряд (если таких нет, то первые три). Демо-данные считаются от сегодняшней даты.

## Текст поста

Чтобы понять, что у клиента на месяц, не нужно листать по дню. Календарь показывает месяц целиком: где тренировка опубликована, где отдых, где старт. Нужно сдвинуть неделю? Отметьте дни галочкой, с Shift сразу диапазон, и переместите, скопируйте, опубликуйте или удалите их одним действием.

## Заметки

- Из трёх видов календаря выбран «Свёрнуто»: только в нём месяц помещается на один экран. В видах «Блоки» и «Полностью» месяц занимает несколько экранов.
- В демо-данных у клиентов только статусы «опубликована», «отдых» и «соревнование». Черновиков в текущем месяце нет ни у кого, а статусов «выполнено» и «пропуск» в календаре нет совсем, поэтому в ролике их нет.
- Shift+клик движок отправить не умеет, поэтому сцена шлёт событие `click` с `shiftKey` через `S.cue`, а нажатие курсора рисует отдельным `S.span`.
