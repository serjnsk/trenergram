# 23 · Никого не забудете

- **Рубрика:** Фича за 15 секунд
- **Формат:** 9:16, 15 с
- **Площадки:** Reels, Shorts, TikTok
- **Одна мысль:** кабинет сам напомнит, у кого кончается программа, и откроет конструктор на нужной дате
- **Экран:** дашборд, карточка «Нужно внимание» → конструктор клиента на первом дне без программы
- **Серия:** фичи с лендинга, вариант «схема» (упрощённый интерфейс с логотипом, слова только у главного)
- **Сцена:** [scenes/23-reminders.html](../scenes/23-reminders.html), экран [schema/23-reminders.html](../scenes/schema/23-reminders.html)
- **Лендинг:** «Никого не забудете. Кабинет напомнит, у кого кончается программа, и откроет конструктор на нужной дате.»

## Раскадровка

Режим «телефон» со схематичным экраном: шапка с логотипом и разделом «Дашборд», приветствие тренера Алексея (четверг, 16 октября), второстепенное — серыми плашками. Фича выделяется затемнением вокруг, оранжевой рамкой и стикером сбоку, нажатия показаны касанием пальца.

| Время | Кадр / действие | Подпись / стикер |
|---|---|---|
| 0–1 с | Дашборд: приветствие, плашки сводки, карточка «Нужно внимание» | **КАБИНЕТ НАПОМНИТ САМ** / У кого кончается программа |
| 1–3 с | Выделена карточка «Нужно внимание» со счётчиком 3 | стикер «Нужно внимание» |
| 3,1–5,6 с | Выделен список «Кончается программа»: Аня Ким — программа до пт, Олег Руденко — нет недели, Маша Соколова — до 2 ноября | стикер «Кончается программа» |
| 5,7–6,6 с | Выделена «Составить» у Ани, касание | стикер «Составить» |
| 6,6–7,6 с | Экран сменяется: «Конструктор», клиент Аня Ким, неделя 15–20, выбрана суббота 18 | **КОНСТРУКТОР — НА НУЖНОЙ ДАТЕ** / Первый день без программы |
| 7,6–9,8 с | Выделена дата «Сб 18» в полосе недели | стикер «Суббота, 18 октября» |
| 9,9–12,3 с | Выделен пустой день «Суббота, 18 октября» — «Тренировки нет, первый день без программы» | стикер «Открылся на нужной дате» |
| 12,4–15 с | Логотип и слоган | Автоматизируем тренерскую рутину |

## Текст поста

Программа у клиента закончилась в пятницу, а вы вспомнили в понедельник? Так больше не будет. На дашборде кабинет сам покажет, у кого кончается программа: «до пятницы», «нет недели», «до 2 ноября». Нажмите «Составить» — конструктор откроется сразу на первом дне без тренировок. Никого не забудете.
