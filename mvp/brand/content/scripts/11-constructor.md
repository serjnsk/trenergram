# 11 · Конструктор тренировок

- **Рубрика:** Фича за 15 секунд
- **Формат:** 9:16, 15,2 с
- **Площадки:** Reels, Shorts, TikTok
- **Одна мысль:** неделя клиента на одном экране, а готовый блок встаёт в день одним касанием
- **Экран:** конструктор: неделя Ивана Петрова, день «Вторник», шторка «Мои блоки»
- **Серия:** фичи с лендинга, вариант «схема» (упрощённый интерфейс с логотипом, слова только у главного)
- **Сцена:** [scenes/11-constructor.html](../scenes/11-constructor.html), экран [schema/11-constructor.html](../scenes/schema/11-constructor.html)
- **Лендинг:** «Конструктор тренировок»

## Раскадровка

Режим «телефон» со схематичным экраном: шапка с логотипом и разделом «Конструктор», клиент Иван Петров, второстепенное — серыми плашками. Фича выделяется затемнением вокруг, оранжевой рамкой и стикером сбоку, нажатия показаны касанием пальца.

| Время | Кадр / действие | Подпись / стикер |
|---|---|---|
| 0–1 с | Неделя 13–19 октября: Пн «Сила», Вт «Сила + AMRAP», Ср «Отдых», Чт «Тяга + EMOM», Пт «Гимнастика», Сб «Меткость», Вс «Отдых» | **НЕДЕЛЯ КЛИЕНТА НА ОДНОМ ЭКРАНЕ** / Дни, блоки, упражнения из базы |
| 1–3 с | Выделена вся неделя | стикер «Вся неделя на одном экране» |
| 3,4 с | Касание «Вт» → неделя сворачивается в полосу дней, открывается вторник: «Разминка» (Гребля 500 м), «Силовая» (Присед со штангой 5×5 70 %, Жим лёжа 4×6 75 %) | |
| 4,4–6,4 с | Выделена кнопка «+ Мои блоки», касание в 6 с | стикер «Шторка «Мои блоки»» |
| 7–8,8 с | Снизу выезжает шторка «Мои блоки»: Разминка «Утро», AMRAP 12 «Классика», Силовая · присед, Заминка | **ГОТОВЫЕ БЛОКИ — В ОДИН ТАП** / Без таблиц и формул; стикер «Ваши заготовки» |
| 8,9–9,8 с | Выделен AMRAP 12 «Классика», касание | |
| 10,4–12,5 с | Шторка закрылась, в дне новый блок «Комплекс AMRAP 12»: Подтягивания 10, Махи гирей 15 · 24 кг | стикер «Блок уже в дне» |
| 12,6–15,2 с | Логотип и слоган | Автоматизируем тренерскую рутину |

## Текст поста

Вся неделя клиента — на одном экране: дни, блоки, упражнения из базы. Открыли день, нажали «Мои блоки» — и готовая разминка, силовая или AMRAP встаёт в тренировку одним касанием. Меняйте порядок, копируйте дни, собирайте из шаблонов — без таблиц и формул.
