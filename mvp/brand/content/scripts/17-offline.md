# 17 · Офлайн-режим (скоро)

- **Рубрика:** Фича за 15 секунд
- **Формат:** 9:16, 15 с
- **Площадки:** Reels, Shorts, TikTok
- **Одна мысль:** скоро тренировка будет храниться у клиента в телефоне: пропала связь — он всё равно отмечает подходы, а результаты уйдут тренеру сами, когда сеть вернётся
- **Статус фичи:** скоро — бейдж «Скоро» на плашке «Нет сети», слово «скоро» в первой подписи

- **Серия:** фичи с лендинга, вариант «схема» (упрощённый интерфейс с логотипом, слова только у главного)

## Раскадровка

Режим «телефон» со схематичным экраном клиента: шапка со знаком, «Тренерграм», «Тренер Алексей» и значком сети. Фича выделяется затемнением вокруг, оранжевой рамкой и стикером сбоку, нажатия показаны касанием пальца.

| Время | Кадр / действие | Подпись / стикер |
|---|---|---|
| 0–0,7 с | Тренировка клиента, сеть есть | **НЕТ СЕТИ — ТРЕНИРОВКА ЕСТЬ** / Офлайн-режим — скоро в приложении |
| 0,7–3 с | Значок сети перечёркнут, выезжает тёмная плашка «Нет сети · Скоро — Тренировка на телефоне — отмечайте, всё сохранится» | стикер «Нет сети — всё на месте» |
| 3,2–6 с | Выделен блок «Силовая»: присед со штангой, три касания отмечают подходы 5 × 132,5 кг | стикер «Подходы отмечаются» |
| 6,1–7,4 с | Выделена нижняя строка «Сохранено на телефоне: 3» | стикер «Сохранено на телефоне» |
| 7,5–9,3 с | Значок сети снова зелёный, плашка меняется на «Сеть есть — Результаты у тренера», внизу «Отправлено тренеру» | **СЕТЬ ВЕРНУЛАСЬ — ВСЁ У ТРЕНЕРА** / Результаты уйдут сами, без кнопок; стикер «Сеть вернулась» |
| 9,5–12,3 с | Снизу выезжает карточка из ленты тренера: «Пришло тренеру — Иван Петров записал результат — Присед со штангой — 3 подхода × 5 по 132,5 кг — Пришло, как только появилась сеть» | стикер «Пришло тренеру» |
| 12,4–15 с | Логотип и слоган | Автоматизируем тренерскую рутину |

## Текст поста

Скоро в Тренерграме — офлайн-режим. Программа будет храниться у клиента в телефоне, а не в облаке. В подвале зала пропала связь — клиент всё равно видит тренировку и отмечает подходы. А как только сеть вернётся, результаты сами уйдут вам: «Иван Петров записал результат — присед, 3 подхода × 5 по 132,5 кг». Без кнопок и без «потом допишу».

## Заметки

- Фича ещё не готова: в ролике это честно помечено бейджем «Скоро» и подписью. Когда выйдет — убрать бейдж и «скоро» из sub.
- Значок «нет сети» нарисован в шапке приложения (статус-строку телефона рисует движок, её не трогаем).
