# 01 · Тренировка в один клик

- **Рубрика:** Фича за 15 секунд
- **Формат:** 9:16, 13,5 с
- **Площадки:** Reels, Shorts, TikTok
- **Одна мысль:** прошлую тренировку клиента не нужно набирать заново, её можно скопировать из календаря одним кликом
- **Экран:** `constructor.html`: пустой день, правая панель «Календарь»
- **Сцена:** [scenes/01-copy-workout.html](../scenes/01-copy-workout.html)

## Раскадровка

| Время | Кадр / действие | Подпись |
|---|---|---|
| 0–1,2 с | Весь кабинет: пустой день «Новая тренировка» | **ТРЕНИРОВКА В ОДИН КЛИК** / Любой прошлый день клиента — прямо в конструктор |
| 1,2–2,6 с | Наезд на правую панель с календарём | |
| 2,2–3,5 с | Курсор на ближайший прошлый день с тренировкой, клик: снизу показывается превью тренировки (день выбирается сам, демо-данные считаются от сегодняшней даты) | |
| 3,7–5,2 с | Подсветка превью тренировки | |
| 4,6–5,7 с | Курсор на «Скопировать в …», клик | |
| 6,2–7,6 с | Наезд на конструктор: тренировка уже в дне | **ОСТАЁТСЯ ПОПРАВИТЬ И СОХРАНИТЬ** / Схема, нагрузка, заметки — всё уже на месте |
| 8,3–10,5 с | Панорама к «Сохранить», клик, подсветка | |
| 10,9–13,5 с | Логотип и слоган | Автоматизируем тренерскую рутину |

## Текст поста

Тренировка на понедельник почти как в субботу? Не набирайте заново. Откройте календарь клиента прямо в конструкторе, выберите день и нажмите «Скопировать». Поправьте пару цифр и сохраните.
