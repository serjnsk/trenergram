# Контент для соцсетей

Ролики про фичи, кейсы, ролики с актёрами. Всё, что можно показать экраном продукта, делаем из **живого прототипа**: сцена открывает настоящую страницу кабинета (`constructor.html`, `calendar.html`…) в iframe и анимирует поверх неё камеру, курсор, подсветки и подписи. Ничего не перерисовываем: поменяли экран в прототипе, перерендерили ролик.

Адрес: https://serjnsk.github.io/trenergram/prototype/brand/content/ (сценарии публичные).

## Что где

| Путь | Что |
|---|---|
| [plan.md](plan.md) | Контент-план и банк идей |
| [scripts/](scripts/) | Сценарии и раскадровки, по файлу на ролик (`_template.md` — шаблон) |
| [scenes/](scenes/) | Моушн-сцены: `NN-имя.html` + общий движок `engine.js` / `engine.css` |
| [render.mjs](render.mjs) | Рендер сцены в MP4 |
| `exports/` | Локальные рендеры. **Не в git**: готовые ролики загружаются в облако |

## Форматы

| Формат | Размер | Где |
|---|---|---|
| `9:16` | 1080×1920 | Reels, Shorts, TikTok, Stories (по умолчанию) |
| `4:5` | 1080×1350 | Лента Instagram |
| `1:1` | 1080×1080 | Лента, Telegram |
| `16:9` | 1920×1080 | YouTube, лендинг |

## Стиль

- Заголовки: Montserrat Black, капс, трекинг −3,5 %. Акцентное слово выделяется оранжевым `#FC5200` (в тексте подписи — `*слово*`).
- Подзаголовки: Inter 600.
- Фон: тёплый `#F7F3EF` (`theme:'light'`), тёмный `#141414` (`'dark'`) или оранжевый (`'orange'`).
- Финал: логотип и слоган «Автоматизируем тренерскую рутину».
- Одна мысль на ролик. Подпись живёт 3–5 секунд, максимум 6 слов в заголовке.
- Десктопный кабинет в вертикальном кадре мелкий, поэтому камера всегда наезжает на действие (`S.focus`), а целиком экран показывается только в первом кадре.

## Как сделать ролик

1. Сценарий: скопировать `scripts/_template.md`, расписать по секундам.
2. Сцена: скопировать `scenes/01-copy-workout.html`, поменять страницу и таймлайн. API описано в начале `scenes/engine.js`.
3. Предпросмотр: открыть сцену с локального сервера из `mvp/` (`python3 -m http.server 8770`, затем `http://localhost:8770/brand/content/scenes/<сцена>.html`). Пробел ставит на паузу, R запускает с начала.
4. Кадр для проверки композиции:
   ```bash
   node render.mjs scenes/01-copy-workout.html --still 6.5
   ```
5. Ролик целиком:
   ```bash
   node render.mjs scenes/01-copy-workout.html
   ```
   Готовый файл появится в `exports/<сцена>.mp4`, дальше его загружают в облако.

Первая установка: `brew install ffmpeg`, затем `npm install` в этой папке. Нужен Google Chrome. Рендер сам поднимает сервер и запускает чистый профиль браузера, поэтому демо-данные прототипа всегда начинаются с исходного состояния.

## Подводные камни

- Chrome запускаем **без** `--disable-gpu`, иначе плашки календаря рисуются пустыми.
- Время сцены одно на всё: в рендере CSS-анимации страницы стоят на паузе и двигаются кадрами. Таймеры JS (`setTimeout`) в самой странице идут по настоящим часам, так что если действие в прототипе ждёт таймер, давайте ему запас по времени.
- Селекторы берите устойчивые: `#id`, класс блока или поиск кнопки по тексту (см. `btn()` в сцене 01). Если элемент не найден, в консоли рендера появится `[scene] не найдено`.
