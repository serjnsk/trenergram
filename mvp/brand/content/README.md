# Контент для соцсетей

Ролики про фичи, кейсы, ролики с актёрами. Всё, что можно показать экраном продукта, делаем из **живого прототипа**: сцена открывает настоящую страницу кабинета (`constructor.html`, `calendar.html`…) в iframe и анимирует поверх неё камеру, курсор, подсветки и подписи. Ничего не перерисовываем: поменяли экран в прототипе, перерендерили ролик.

Адрес: https://serjnsk.github.io/trenergram/prototype/brand/content/ (сценарии публичные).

## Что где

## Студия — просмотр роликов

```bash
npm run studio
```

Откроется `http://localhost:8790`. Студия работает только локально, на Pages показывает заглушку.

- **Слева** — все видео из `exports/`, включая подпапки (ролики с актёрами и монтаж кладите туда же). Есть превью, длительность, формат и поиск (`/`). Новые файлы появляются сами.
- **В центре** — рамка телефона: iPhone SE, iPhone 15, 15 Pro Max, Pixel 8 или «без рамки» в исходном размере. Сверху можно наложить интерфейс Reels, TikTok или Shorts и включить безопасную зону (`G`): так видно, что перекрывают кнопки и подписи площадки. «Обрезать как в ленте» (`F`) показывает, сколько срежется по бокам на вытянутом экране.
- **Справа** — сцены со статусом («Готово», «Устарело — сцена менялась», «Не отрендерено») и кнопкой «Рендер». Готовый ролик сразу открывается в телефоне.
- **Клавиши:** пробел — пуск, `←` `→` — на кадр, с `Shift` — на секунду, `↑` `↓` — соседнее видео, `1`–`5` — устройство, `L` — повтор, `M` — звук.

| Формат | Размер | Где |

## Стиль

- Заголовки: Montserrat Black, капс, трекинг −3,5 %. Акцентное слово выделяется оранжевым `#FC5200` (в тексте подписи — `*слово*`).
- Подзаголовки: Inter 600.
- Фон: тёплый `#F7F3EF` (`theme:'light'`), тёмный `#141414` (`'dark'`) или оранжевый (`'orange'`).
- Финал: логотип и слоган «Автоматизируем тренерскую рутину».
- Одна мысль на ролик. Подпись живёт 3–5 секунд, максимум 6 слов в заголовке.
- **Раскладка 9:16 под интерфейс площадок.** Верхние 220 px занимает шапка Reels/TikTok, там ничего важного. Заголовок начинается с 230 px, экран прототипа стоит в полосе 620–1500 px, нижние 420 px отданы под подпись поста и кнопки. Задаётся в `engine.js` (`SAFE`), проверяется в студии с включённой «Безопасной зоной».
- Демо-данные прототипа считаются от сегодняшней даты. В сценах не привязывайтесь к числам: ищите элемент по признаку (см. `lastDay` в сцене 01).
- Десктопный кабинет в вертикальном кадре мелкий, поэтому камера всегда наезжает на действие (`S.focus`), а целиком экран показывается только в первом кадре.

## Ролики по фичам: режим «телефон»

Вертикальный ролик показывает **мобильную вёрстку кабинета целиком в рамке телефона**, без наездов камеры. Десктопные экраны в 9:16 не берём.

- `S.phone('../../../constructor.html')` — страница в ширину 390 (включается `mobile.css`), телефон 1,5× под заголовком, на тёплом фоне с крупными формами.
- `S.spot(t0, t1, target, { label, side, dy, pad })` — фича выделяется: экран вокруг притемняется, элемент обводится оранжевой рамкой, сбоку стикер с подписью (`*слово*` — оранжевым).
- `S.tap(t, target)` — касание пальцем вместо курсора, клик уходит в страницу.
- `S.scroll(t0, t1, y)` — прокрутка страницы внутри телефона.
- `S.pageCss('…')` — стиль, подставляемый в страницу, если мобильная вёрстка ломает кадр. Каждую такую правку отмечайте в сценарии: её нужно перенести в прототип.

Образец — `scenes/04-text-workout.html`.

**Вариант «схема»** — тот же ролик на схематичном экране: `S.phone('schema/<имя>.html')`, где страница — упрощённый интерфейс (второстепенное серыми плашками, настоящие слова только у главного), а состояния переключаются кликами или функциями `window.ST`. Образец — `scenes/04-text-workout-schema.html` и `scenes/schema/04-text.html`.

## Как сделать ролик

1. Сценарий: скопировать `scripts/_template.md`, расписать по секундам.
2. Сцена: скопировать `scenes/01-copy-workout.html`, поменять страницу и таймлайн. API описано в начале `scenes/engine.js`.
3. Предпросмотр: открыть сцену с локального сервера из `mvp/` (`python3 -m http.server 8770`, затем `http://localhost:8770/brand/content/scenes/<сцена>.html`). Пробел ставит на паузу, R запускает с начала.
4. Кадр для проверки композиции:
   ```bash
   node render.mjs scenes/01-copy-workout.html --still 6.5
   ```
5. Ролик целиком:
   ```bash
   node render.mjs scenes/01-copy-workout.html
   ```
   Готовый файл появится в `exports/<сцена>.mp4`, дальше его загружают в облако.

Первая установка: `brew install ffmpeg`, затем `npm install` в этой папке. Нужен Google Chrome. Рендер сам поднимает сервер и запускает чистый профиль браузера, поэтому демо-данные прототипа всегда начинаются с исходного состояния.

## Подводные камни

- Chrome запускаем **без** `--disable-gpu`, иначе плашки календаря рисуются пустыми.
- Время сцены одно на всё: в рендере CSS-анимации страницы стоят на паузе и двигаются кадрами. Таймеры JS (`setTimeout`) в самой странице идут по настоящим часам, так что если действие в прототипе ждёт таймер, давайте ему запас по времени.
- Селекторы берите устойчивые: `#id`, класс блока или поиск кнопки по тексту (см. `btn()` в сцене 01). Если элемент не найден, в консоли рендера появится `[scene] не найдено`.
