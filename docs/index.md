# Тренерграм — приложение для тренеров

Внутренняя документация по разработке приложения для ведения тренировок: для тренеров по кроссфиту, тренажёрному залу и смежным видам спорта.

Это единый источник требований для разработчика и дизайнера.

## Прототип

Кликабельный прототип в объёме MVP. Кабинет тренера — дашборд, клиенты и группы, календарь, конструктор тренировок, базы упражнений, блоков, тренировок и программ, профиль, бренд. Приложение клиента — стенд с картой экранов: вход и создание аккаунта, главная, тренировка, лента, профиль, настройки, светлая и тёмная тема.
