# 03 — MVP

Первый этап: что именно строится, чтобы тренер начал работать в продукте. Дальше — [04 — Этап 2](04-stage-2.md) и [05 — Этап 3](05-stage-3.md).

**Цель:** тренер ведёт реальных клиентов в приложении и отказывается от Google-таблиц. Проверяем главную гипотезу — конструктор быстрее и удобнее всего, чем тренер пользуется сейчас.

**Минимальный рабочий цикл:** тренер составил программу → клиент выполнил и записал результат → тренер увидел.

## Скелет (обязательное ядро)

| Модуль | Что входит в MVP |
|---|---|
| Визуал | Дизайн-система: палитра, типографика, радиусы, знак — зафиксированы на странице бренда в прототипе. Кабинет тренера следует ей; клиентское приложение — по референсу HWPO Training |
| Регистрация | Ссылка тренера (REG-1), вход по номеру телефона (REG-2), рабочее пространство тренера (REG-3) |
| Конструктор: составление | Вручную (CON-1), из базы упражнений (CON-2), из готовых блоков (CON-3), обычным текстом и вставкой готового текста (CON-5), drag-and-drop (CON-8), тип блока и настройка комплекса (CON-18), запись упражнения структурой и текстом (CON-19), черновик и публикация (CON-20), суперсет (CON-21) |
| Конструктор: назначение | Одному клиенту (CON-9), массовое назначение (CON-10) |
| Конструктор: копирование | Выбор произвольного набора дней и копия набором (CON-4), массовое копирование (CON-12), перетаскивание между днями (CON-13), перенос набора (CON-14), правила раскладки и отмена действия (CON-22) |
| Конструктор: расчёт нагрузки | Рабочие веса от 1ПМ/3ПМ/5ПМ и ввод максимума на месте (CON-16), автообновление после нового рекорда (CON-17) |
| Шаблоны | Свои блоки с папками (TPL-1), библиотека шаблонов по уровням блок → тренировка → программа (TPL-2), составление и копирование из шаблонов (TPL-3) |
| Бренд тренера | Логотип, название профиля, цвета, фон, аватар, обложка (BRD-1) |
| База упражнений | Стартовая база с техникой, демонстрацией и связями «замены/прогрессии» (EX-1), свои упражнения без видео (EX-2), гибкие показатели (EX-3) — заложить в модель данных сразу, даже если UI простой |
| Календарь | Месяц одного клиента (CAL-1), статус дня: отдых, черновик, опубликована, соревнование (CAL-2), переключение плотности показа (CAL-3) |
| Дашборд | Лента важных событий (DSH-1), статистика аккаунта (DSH-2), очередь составления (DSH-3) |
| Выполнение клиентом | Просмотр тренировок (CLI-1), запись весов, повторов, ПМ и результатов (CLI-2) |
| Оффлайн клиента | Чтение программы и запись результатов без сети (CLI-3) — архитектура local-first с первого дня (NFR-3) |
| Профиль спортсмена | Основное (PRO-1), антропометрия (PRO-2), максимумы 1/3/5ПМ (PRO-4), история показателя с графиком (PRO-6), карточка клиента у тренера (PRO-8) |
| Профиль тренера | Основные данные (TRN-1), ссылка приглашения клиентов (TRN-3), смена пароля (TRN-5) |
| Коммуникация | Комментарий клиента к тренировке (COM-1) и к упражнению (COM-2), ответ и реакции тренера без видеоответов (COM-3), сообщение к дню и заметка к блоку для клиента (COM-4), приватная заметка о клиенте (COM-5) |
| Админ | Список тренеров (ADM-1), список клиентов (ADM-2), десктоп-сайт админа (ADM-3) |
| Платформы | Мобильные приложения iOS/Android (NFR-1), **веб-версия конструктора для тренера** (NFR-2) — составление программ почти всегда идёт с компьютера, local-first архитектура (NFR-3), скорость конструктора как метрика (NFR-4) |

## Сознательно НЕ входит в MVP

Платежи (первым тренерам даём бесплатно/вручную), групповые программы, импорт из Excel и TRNR, таймер, видеозагрузка, анкеты, уведомления, курсы, лидерборды, ИИ, публичная страница тренера.

**Критерий готовности MVP:** 5–10 живых тренеров ведут своих клиентов неделями без возврата к таблицам.
