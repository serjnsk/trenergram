# 05 — Решения и открытые вопросы

Реестр продуктовых и технических решений, которые не выводятся из остальных документов, и вопросов, которые предстоит закрыть. У каждого пункта стабильный ID (OQ-N) — для ссылок из задач и обсуждений.

## Принятые решения

- **OQ-1. Название.** «Тренерграм». Белый wordmark со срезом 45° на оранжевом #FC5200, знак — «Т», короткий знак — «ТМ». Домен, имена в App Store и Google Play, товарный знак — до запуска.
- **OQ-2. Платформы тренера.** Веб-версия конструктора входит в MVP; мобильные приложения — для всех ролей.
- **OQ-3. Технологический стек.** React Native + Expo, React + Vite, TypeScript-монорепо; оффлайн — PowerSync (self-hosted), SQLite ↔ PostgreSQL; backend — Node.js/NestJS, Redis, S3; хостинг в РФ. Подробности — в [06 — Технологический стек](06-tech-stack.md).
- **OQ-4. Платёжный провайдер.** Т-Банк; интеграция — этап 2.
- **OQ-5. Комиссия App Store / Google Play.** Подписка тренера на сервис (PAY-8) оплачивается только в веб-версии.
- **OQ-6. Хранение видео.** Своё S3-совместимое хранилище в РФ + транскодинг (ffmpeg) + HLS.
- **OQ-7. Персональные и медицинские данные.** Юридическая схема согласована; 152-ФЗ учитывается при реализации профиля (PRO-3).
- **OQ-9. Стартовая база упражнений.** Разовый выкуп датасета EDB Exercise Intelligence (exercisedb.io), лицензия Cross-Platform $599, хостинг у себя. Русская локализация и ~80–120 кроссфит-движений — своими силами.
- **OQ-10. Текст ↔ структура в конструкторе.** Канонический формат программы — структурированные данные; текстовый ввод — интерфейс поверх структуры с распознаванием на лету.
- **OQ-11. Выплаты тренерам.** Без внутреннего баланса и вывода средств: тренер привязывает карту, деньги клиентов приходят ему напрямую (PAY-7).
- **OQ-13. Программа — последовательность дней произвольного ритма.** Единица плана — день: тренировка или отдых. Неделя — способ смотреть, не сущность модели.
- **OQ-14. Календарь — месяц одного клиента.** Общая картина по всем клиентам — на дашборде (модуль DSH).
- **OQ-15. Тип блока — явное поле.** Разминка, силовая, комплекс, заминка, растяжка, подкачка, гимнастика; формат (AMRAP, EMOM, на время, табата, интервалы, death by, не на время) — настройка комплекса, а не самостоятельный тип.
- **OQ-16. Запись упражнения — структура или текст.** Способы взаимоисключающие; сложная запись хранится текстом при узнанном упражнении. RPE исключён из выбора нагрузки, остаётся показателем выполнения (EX-3).
- **OQ-17. Результат массовых операций — всегда черновик.** Личные данные клиента не копируются; занятый день заменяется после предупреждения; любое действие отменяется.

## Открытые вопросы

- **OQ-8. Модель монетизации платформы.** Не зафиксирована; оформляется отдельным документом `09-monetization.md`. Контекст: TRNR берёт от 1000 ₽/мес; варианты — подписка по числу клиентов, комиссия с платежей, гибрид.
- **OQ-12. Экономика видеохранилища.** Стоимость хранения и трафика на одного тренера, лимиты в тарифах (модуль VID, этап 2). Связано с OQ-8.
- **OQ-18. Заметка к упражнению.** Заметка есть у блока и сообщение — у всей тренировки; нужна ли отдельная заметка к упражнению внутри блока. Влияет на модель данных.
- **OQ-19. Назначение копирует программу или разделяет её.** Меняется ли программа у уже назначенных клиентов, когда тренер правит её после назначения (CON-10, CON-11). Ответ задаёт модель данных и цену групповых изменений.
- **OQ-20. Полный словарь форматов комплекса.** Какой список форматов считать полным — задаёт границу «распознали / оставили текстом» (CON-5, CON-18).
